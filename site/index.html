URUPEMA

Filtro Post-Queue & Higienizador de MIME
Dissecador cirúrgico de MIME em Rust síncrono. Recebe o payload bruto RFC 5322 via stdin do Postfix, expurga scripts, rastreadores e ruídos de newsletter, gerando Markdown limpo e HTML estritamente higienizado.

01. ZERO-COPY MIME

Parser ultrarrápido baseado em mail-parser dissecando cabeçalhos e árvores multipart com alocação mínima.

02. TXT AUTO MARKDOWN

Conversão determinística de blocos HTML em texto legível preservando links e estrutura via html2text.

03. HIGIENE CIRÚRGICA

Eliminação impiedosa de rastreadores, CSS externo e vetores maliciosos com allowlist estrita via ammonia.

TRANSPORTE POSTFIX (master.cf)

urupema  unix  -  n  n  -  -  pipe
  flags=Rq user=urupema argv=/usr/local/bin/urupema
  --sender=${sender} --recipient=${recipient}
